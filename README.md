# chinese_calendar_finder

Скрипт, который вычисляет конкретные даты по запросу вида «день Дракона в Месяц Крысы 3170 года».
Написан при помощи QWEN Ai

## Как это работает (важная теория)

В китайском календаре дни и месяцы описываются 12 «земными ветвями» — животными:

- **День** образует непрерывный 12-дневный цикл, не зависящий от Луны. Поэтому заданное животное дня повторяется каждые 12 дней (в месяце их бывает 2–3).
- **Месяц** привязан не к новолуниям, а к солнечным отрезкам **цзеци** (节气): «Месяц Крысы» начинается с Большого снега/Зимнего солнцестояния (декабрь), «Месяц Тигра» — с Личуня (4 февраля) и т.д. Именно поэтому вариантов дат может быть несколько — скрипт находит все.

## Возможности скрипта

1. Запрашивает **год** (с валидацией ввода).
2. Предлагает выбрать **животное дня** из списка 1–12 (Крыса…Кабан, с китайскими иероглифами 龙/子…).
3. Предлагает выбрать **животное месяца** из такого же списка.
4. Выводит **все подходящие даты**: день недели, точную дату, дату начала цзеци-месяца с названием сезона, лунную дату и полные столпы Бацзы (год/месяц/день в цикле 60).
5. Особое внимание уделено «переходящим» месяцам Крысы и Быка (они начинаются в декабре/январе и захватывают соседний григорианский год) — такие даты помечаются примечанием.
6. Самопроверка: контроль кратности интервалов между найденными датами цифре 12.

## Точность и надёжность

- Животное дня считается автономно через юлианские дни (JD+5 mod 12) — сверено со 800 случайными датами против библиотеки `sxtwl` (0 расхождений).
- Границы месяцев берутся из астрономических цзеци библиотеки **`sxtwl`** (`pip install sxtwl`); если её нет — используется резервная аппроксимация по средним датам чжунци (±1 день) с предупреждением.
- Диапазон лет проверен вплоть до 3170 и дальше (sxtwl корректно работает до ~8000 г.).

## Пример вывода («день Дракона в Месяц Крысы 3170 года»)

Найдено вариантов: 4
1. 05.01.3170 (понедельник) — хвост месяца Крысы, начавшегося 07.12.3169; столпы: 己酉 / 丙子 / 丙子
2. 07.12.3170 (понедельник) — начало месяца Крысы (大雪 Дасюэ); столпы: 庚戌 / 戊子 / 壬子
3. 19.12.3170 (суббота)  — столпы: 庚戌 / 戊子 / 甲子
4. 31.12.3170 (четверг)  — столпы: 庚戌 / 戊子 / 丙子
Примечание: «Месяц Крысы» года 3170 охватывает 07.12.3170 — январь 3171 …
Контроль (OK): интервалы [12, 336] дн.

## Запуск 

`python3 chinese_calendar_finder.py` (зависимость: `pip install sxtwl`)
